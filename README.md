# Poo-riend · 데모 페이지

서버 없이 브라우저 안에서 돌아가는 데모 버전. GitHub Pages에 그대로 올리면 된다.

- 폰/PC 모두 한 링크로 접속 (화면 폭에 따라 자동 전환)
- 데이터는 각자 브라우저 안에만 있고, 새로고침하면 초기화됨
- 함께 있는 친구들(명수, 영케 …)은 데모용 봇

## GitHub Pages로 올리기
1. 이 폴더 안의 파일 전부를 저장소 맨 위(루트)에 올린다 (`index.html`이 루트에 있어야 함)
2. 저장소 Settings → Pages → Source: **Deploy from a branch**, Branch: **main** / **(root)** → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 으로 접속
